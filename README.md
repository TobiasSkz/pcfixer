<h1 align="center">PC Fixer</h1>
<br>

- Proyecto web desarrollado como entregable para la certificación de Desarrollo Web en Coderhouse, enfocado en ofrecer soluciones profesionales de reparación, optimización y mantenimiento de equipos informáticos.

<h3 align="center"> < Características Principales > </h3>
<br>

- Diseño Responsivo (Mobile-First): Adaptabilidad fluida a diferentes tamaños de pantalla (smartphones, tablets y computadoras de escritorio).
  
- Secciones Dinámicas:
  - Presentación clara de identidad y servicios prestados.
  - Información sobre la trayectoria, experiencia y valores enfocados en brindar confianza al cliente.
  - Apartado de servicios detallados (armado de PCs, reparación, optimización).
  - Sección de preguntas frecuentes completamente redactada y posibilidad de soporte personalizado.
  - Formulario de contacto y medios de atención.
- Estilos Modularizados: Estructura de estilos optimizada mediante el uso de preprocesadores.
- Componentes Interactivos: Implementación de elementos visuales dinámicos para una mejor experiencia de usuario (UX).

<br>

***

<h3 align="center"> < Tecnologías Utilizadas > </h3>
<br>

- HTML5: Marcado semántico y estructuración del contenido.
- SASS / SCSS: Preprocesador CSS para una mejor organización, uso de variables y modularización del diseño.
- Bootstrap: Framework CSS para la estructuración de componentes responsivos y grillas.
- JavaScript: Interactividad y dinamismo en la interfaz.
- Git & GitHub: Control de versiones y despliegue continuo mediante GitHub Pages.
